# Revise

The website for Revise — a two-student web studio in Chicago that takes outdated small-business websites and revises them into fast, modern sites.

Hand-coded static site: no frameworks, no templates, no page builders.

## Structure

- `index.html` — the whole site (single page)
- `styles.css` — design system: Fraunces + Inter + Caveat, paper/ink palette with a red-pen accent
- `main.js` — hero canvas animation, scroll reveals, before/after sliders, contact form

## Run locally

Any static server works, e.g.:

```
python -m http.server 4173
```

then open http://localhost:4173.
